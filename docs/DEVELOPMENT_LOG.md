# Development Log

This log summarizes significant progress, decisions, blockers, and milestones for our NASA Space Apps Challenge 2026 project.

It complements GitHub Issues, Pull Requests, and commit history; **it does not duplicate every code change**.

## When to add an entry

Add an entry when a milestone is completed, an important technical or scope decision changes, a major blocker appears or is resolved, or the team reaches a meaningful integration or delivery checkpoint.

- Write the date and milestone/topic.
- Describe verified outcomes, not just intentions.
- Explain consequential decisions briefly.
- Reference GitHub Issues/PRs instead of repeating their discussions.
- Use "None" or omit a subsection if it has nothing to report.
- Add new entries at the top of the **Entries** section (newest first).
